# Contexto do projeto

Antes de alterar layout, conteúdo comercial, identidade visual, imagens ou animações, leia [CONTEXTO-VISUAL.md](CONTEXTO-VISUAL.md). Ele registra a direção visual acordada com o usuário, as alternativas rejeitadas e os cuidados de implementação.

Use esse documento como referência para manter consistência entre sessões. Novas instruções explícitas do usuário prevalecem. Atualize o contexto quando uma nova decisão visual for aprovada; não registre propostas ou detalhes não verificados como aprovações.
